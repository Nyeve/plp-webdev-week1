# Week 1: Introduction to HTML

A beginner web-development exercise for practicing a complete HTML document and preparing work for version control.

## Exercise objectives

- Build a valid HTML document from scratch.
- Use semantic elements to give page content meaningful structure.
- Add descriptive alt text to images and clear, descriptive text to links.
- Save changes as Git commits and publish the project in a Git repository.

## Project files

- `index.html` — the HTML document for the exercise.

## View locally

Open `index.html` directly in a web browser. No build tools or dependencies are required.

## Save a version with Git

From the project directory, stage your changes and create a commit:

```bash
git add index.html README.md
git commit -m "Complete Week 1 HTML exercise"
```
